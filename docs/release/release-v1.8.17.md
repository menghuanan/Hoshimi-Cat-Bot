## **新增 / 优化**

- 新增 QQ 官方机器人管理员快速绑定功能，简化 WebUI 中管理员账号的绑定流程，并同步更新相关构建配置。
- 新增 QQ 官方群目录功能及配套支持，扩展 QQ 官方机器人接入能力。

- 优化 WebUI 页面布局，使空状态内容能够居中显示，并调整相关布局动画。
