## v1.8.14

### 新增 / 优化

* 统一 Docker、Windows、Linux 环境下的 JVM 内存配置，优化 Metaspace、CodeCache 等非堆内存使用。
* 新增启动诊断信息，启动时自动输出部署环境、JVM 参数、Skiko 配置等关键运行信息，方便排查部署问题。
* 优化非堆内存监控逻辑，支持动态识别 JVM CodeCache 上限，并增加告警冷却与迟滞机制，减少误报。
* 完善内存调优相关文档与测试用例。

### 修复

* 修复部分无效 PGC 链接被错误解析的问题。
* 优化 PGC 链接匹配规则，限制 `ss` / `ep` / `md` 标识后的数字长度，过滤异常短标识。
* 增加 PGC 链接合法性校验，避免无效链接进入后续解析流程。
