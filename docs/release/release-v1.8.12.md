# Hoshimi-Cat-Bot v1.8.12 发布说明

**版本号**：v1.8.12
**发布日期**：2026-07-09

---

## 温馨提示

### QQ 官方适配器目前已可使用，但**仍不建议在正式环境中使用**。

目前 QQ 官方适配器已完成主要框架与解析能力适配，但仍存在一定限制：

* ✅ 已支持消息解析
* ✅ 可正常生成解析图片
* ⚠️ 解析结果中的链接目前无法发送
* ⚠️ 订阅功能理论上可用，但同样受链接发送限制
* ⚠️ 暂不建议用于生产环境

如果你只是希望使用 QQ 官方机器人进行 **B站链接解析并获取图片结果**，可以提前体验并反馈问题。

---

## 变更摘要

本次更新重点围绕 **WebUI 配置热重载** 与 **QQ 官方适配器完善** 展开，同时进一步优化配置管理、运行时资源管理以及整体稳定性。

### 后端更新

* WebUI 配置批量热重载正式支持
* 配置保存支持自动回滚
* Tasker 配置支持运行时刷新
* 新增链接解析黑名单配置
* 完善 QQ 官方适配器
* 优化运行时资源释放与热重载稳定性

### 前端（WebUI）更新

* 新增全局 Toast 通知系统
* 配置保存支持变更检测
* 重构订阅编辑弹窗
* 优化暗色主题与动画效果
* 修复弹窗显示异常

---

# 后端更新

## 1. WebUI 配置热重载（本次重点）

本次实现了完整的配置热重载能力。

现在通过 WebUI 保存配置后，无需重启 Bot 即可生效。

支持热重载的内容包括：

* BiliConfig.yml
* BiliData.yml
* bot.yml

同时支持：

* 批量保存多个配置文件
* 自动安装运行时配置
* 失败自动回滚
* 配置代际隔离
* 配置快照校验

大部分配置项均可直接应用到运行中的程序，无需再次启动。

---

## 2. Tasker 与运行时刷新

各类 Tasker 新增运行时刷新能力：

例如：

* 轮询间隔
* 功能开关
* 绘图配置
* 字体配置
* 翻译配置
* 短链接配置

保存配置后即可自动刷新运行状态。

同时：

* 保存订阅后自动刷新运行缓存
* WebUI Host/Port 修改后自动延迟重启，避免中断当前请求

---

## 3. 配置管理重构

配置管理流程进行了全面重构：

* 快照校验
* 磁盘持久化
* 运行态安装

三个阶段完全分离。

新增：

* 配置保存失败自动恢复
* 模板策略自动迁移
* Scope 格式统一
* 热重载失败自动回滚

进一步提升了配置修改的安全性。

---

## 4. 绘图与资源管理优化

热重载期间新增多项资源保护：

* 绘图队列独占清理
* FontManager 热重载
* DrawingQueue 锁机制
* 绘图缓存优化
* 图片配置实时刷新

同时修复：

* 空预约卡片绘制
* 动态列表单条解析失败导致整页失败的问题

进一步提升长时间运行稳定性。

---

## 5. QQ 官方适配器持续完善

本版本继续完善 QQ 官方平台适配器：

新增支持：

* OneBot Base64 图片
* 本地图片发送
* 字符串 Message ID 回复
* 群成员事件
* 订阅事件
* 更多官方事件解析

同时优化：

* 登录命令识别
* 消息过滤
* 图片上传
* 心跳机制
* 自动重连
* 日志降噪

目前整体功能已基本可用，但由于官方平台限制，仍存在链接发送能力不足的问题，因此暂不建议用于正式环境。

---

## 6. Windows 交叉编译 Linux

新增 Windows 平台交叉编译 Linux 发行包能力。

现在可直接在 Windows 环境构建 Linux Release，无需额外 Linux 构建环境。

# 前端（WebUI）更新

## 7. 全局 Toast 通知系统

新增统一 Toast 通知系统。

所有配置保存、订阅管理、密码修改等操作均使用统一提示方式，交互体验更加一致。

---

## 8. 配置保存优化

新增配置变更检测：

只有真正修改过配置时才会发送保存请求。

同时：

* 后端同步跳过无实际变化的热重载
* 减少无效保存与无效重载

---

## 9. WebUI 界面优化

优化多项页面交互：

* 重构订阅编辑弹窗
* 新增顶部标题栏
* 优化响应式布局
* 完善暗色主题
* 新增页面动画
* 新增按钮加载动画

同时：

修复：

* Modal 被父元素裁剪
* Dark Mode 显示异常
* 多处样式细节问题

整体交互体验进一步提升。

---

## 影响说明

本次更新未引入破坏性配置变更。

但由于热重载能力涉及大量底层逻辑调整，建议升级后观察：

* 配置保存是否正常生效
* WebUI 热重载是否符合预期
* Connector 是否正常重载

如发现异常，请及时反馈。

## 反馈时建议附带的信息

如果你在升级到 v1.8.12 后发现问题，建议附带以下信息：

* 使用版本：v1.8.12
* 部署方式：Docker / 裸机 / JAR
* 是否启用 WebUI
* 使用平台：

  * OneBot11
  * NapCat
  * QQ 官方
  * LLBot
* 是否涉及以下场景：

  * 配置热重载失败
  * WebUI 保存异常
  * QQ 官方适配器问题
  * 绘图或字体异常
* 相关日志
* 可复现步骤
