# Hoshimi-Cat-Bot v1.8.10 发布说明

**版本号**：v1.8.10
**发布日期**：2026-04-13

---

## 变更摘要

本次更新主要完成项目品牌统一重命名工作，并修复动态作者信息解析中的字段类型问题。

* 项目正式更名为 Hoshimi-Cat-Bot
* 完成构建、部署、文档及 WebUI 等全链路名称迁移
* 修复动态作者关注状态字段解析错误
* 补充相关单元测试与文档说明

---

## 详细变更说明

### 1. 项目正式更名为 Hoshimi-Cat-Bot

本次版本完成项目名称统一迁移：

* dynamic-bot → hoshimi-cat-bot

涉及范围包括：

* 构建配置
* Docker 部署配置
* WebUI 页面文本
* 项目文档
* CI/CD 流程
* 示例配置与说明文档

需要说明的是：

* 本次仅涉及项目名称调整
* 不涉及业务逻辑修改
* 不涉及配置结构变更
* 不涉及数据迁移

👉 对现有功能和运行逻辑没有影响。

---

### 2. 修复动态作者关注状态解析

修复哔哩哔哩动态接口中关注状态字段的解析问题。

此前：

* following 字段被定义为 Boolean 类型

实际接口返回：

* following 为数字状态码

本次调整：

* following 字段类型：

  * Boolean? → Int?

同时：

* 更新相关代码注释
* 补充解码测试
* 验证不同状态码场景下的解析行为

👉 提高动态作者信息解析的准确性，避免潜在的数据兼容问题。
