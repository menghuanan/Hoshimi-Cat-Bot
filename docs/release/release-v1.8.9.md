# BiliBili 动态推送 Bot v1.8.9 发布说明

**版本号**：v1.8.9
**发布日期**：2026-05-26

---

## 变更摘要

本次更新主要围绕 WebUI 功能完善、订阅系统增强以及后端稳定性优化展开。

### 前端（WebUI）更新重点

* 优化 WebUI 跨域与代理兼容性
* 重构订阅编辑与管理界面
* 新增群聊范围限定能力
* 完善前端表单校验与错误提示
* 优化 Dashboard 展示布局与状态卡风格

### 后端更新重点

* 重构推送记录与订阅信息结构
* 新增订阅过滤器 / 模板群聊限定逻辑
* 优化配置写入与兼容行为
* 调整认证性能与协程调度
* 修复日志、配置与运行时边界问题

---

# 前端（WebUI）变更

## 1. WebUI 跨域与代理兼容性增强

重构 WebUI 的 CORS 校验逻辑：

* 支持从代理头自动识别合法入口地址
* 兼容以下部署场景：

  * FRP
  * Cloudflare Tunnel
  * 端口映射
  * 内网穿透
  * 内网组网

同时：

* 拦截非法跨域请求
* 新增多场景代理测试用例

👉 更适合公网代理与隧道部署。

---

## 2. Dashboard 首页优化

首页状态卡与推送记录展示进行了统一重构：

### 状态卡

* 标准化状态卡色调系统
* 引入类型安全限制，避免任意 Tailwind 色值污染
* 新增：

  * resolveLifecycleTone
  * resolveBooleanStatusTone

### 推送记录

* 重构推送记录布局
* 限制最近推送仅展示 7 条
* 优化时间格式：

  * 固定中文年月日时分显示
* 仅显示订阅名称，减少冗余信息

👉 首页整体布局与视觉一致性得到明显改善。

---

## 3. 订阅编辑器增强

重构订阅编辑与管理体验：

### 新增能力

* 推送群聊编辑器
* 分组订阅 ID 管理
* 动态过滤器目标群聊选择
* 模板目标群聊选择
* 主题色目标群聊限定

### 新增支持

* 分组订阅支持：

  * UID
  * ss
  * md
  * ep

同时：

* 统一术语：

  * “订阅UID” → “订阅ID”

👉 WebUI 已基本具备完整订阅管理能力。

---

## 4. 表单与交互优化

新增大量前端前置校验：

* 设置项校验
* 订阅创建校验
* 非法输入拦截
* 错误提示优化

同时：

* 群管理员设置改为卡片式编辑
* 优化订阅编辑器弹窗布局
* 修复番剧不支持配置项仍显示的问题

👉 显著减少无效请求与错误操作。

---

# 后端变更

## 5. 推送记录与统计逻辑调整

推送记录字段进行了统一：

* `summary`
  → `subscriptionInfo`

同时：

* 重构推送摘要生成逻辑
* 日期切换时保留最近记录
* 不再每日清空历史展示数据

👉 推送记录结构更加统一，便于前后端维护。

---

## 6. 订阅规则与群聊范围支持（重要）

新增“目标群聊限定”能力：

支持以下配置按群聊生效：

* 动态过滤器
* 模板
* 主题色

后端新增：

* targetGroups 参数
* 群聊范围校验逻辑
* 定向规则写入能力

👉 不再默认全局扩散配置。

---

## 7. 配置与兼容性修复

修复多个 WebUI 配置边界问题：

### OneBot11 Token

* token 缺失时保留旧值
* 避免前端未修改时被覆盖为空

### 管理员配置

* 修复保存 bot 配置时误覆盖管理员问题
* 后端统一处理默认值与规范化逻辑

### 主题色

* 支持空颜色值恢复默认主题色

---

## 8. 认证与性能优化

优化认证链路：

* PBKDF2 迭代次数：

  * 120000 → 60000
* 哈希与文件 IO 切换至 IO 调度器
* 认证相关逻辑改为挂起函数

👉 降低 WebUI 登录与改密延迟。

---

## 9. 文档与工程体系完善

新增项目级开发规范文档：

* AGENTS.md
* 架构设计说明
* 模块职责说明
* 运维与部署文档

同时：

* 清理历史 WebUI Phase4 文档
* 修复 Windows 中文路径测试问题
* 清理 BOM 字符

---

## 10. 其他修复

* 修复 BiliClient 首次失败即输出 warn 日志的问题
* 优化日志打印时机
* 减少网络抖动导致的误告警
