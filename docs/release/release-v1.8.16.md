## v1.8.16

### 新增 / 优化

* 优化动态轮询筛选逻辑，重构 `DynamicCheckTasker`，提取动态排除类型列表与通用过滤函数，提升代码复用性与可维护性。
* 替换原有 `banType` 变量设计，统一动态类型过滤处理逻辑。
* 新增 `ModuleAuthor.following` 字段兼容反序列化器，支持布尔值、`0/1` 数字、`null` 以及字段缺失等多种 B 站返回格式。
* 新增动态轮询过滤测试用例，覆盖不同动态类型筛选场景。
* 扩展动态列表解析测试，增加新序列化场景与过滤逻辑验证。
* 更新相关文档，同步新增测试项、检查清单及使用说明。

### 修复

* 修复部分 B 站动态接口返回数据格式变化导致 `following` 字段反序列化失败的问题。
* 提升动态列表解析兼容性，避免因关注状态字段类型变化导致轮询任务异常。
