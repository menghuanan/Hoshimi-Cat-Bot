## WebUI 系统配置与日志页局部文字偶发模糊（待现场复核）

- 症状：用户反馈这两个页面的部分文字偶发模糊，怀疑遮罩越界。
- 源码检查：日志页没有页面遮罩；设置页扫码和快速绑定弹窗经 `ModalPortal` 挂载，关闭后卸载。背景模糊只用于弹窗遮罩和侧栏底部，尚未发现错误覆盖的代码证据。
- 已处理的可疑因素：移除页面、配置分组和字段常驻的 `will-change: opacity, transform`，配置入场动画由 `both` 改为 `backwards`，使动画结束后恢复普通布局；减少动态效果偏好同时禁用路由入场。
- 验证边界：lint、116 项 Vitest 用例、5 项 Node 版本检查和前端构建通过；当前检查环境无法启动 Edge 自动化，浏览器本地预览连接超时，因此未复现原始模糊，也不能认定已确认唯一根因。
- 复核方式：更新前端产物并强制刷新后，在原浏览器缩放与显示缩放下切换配置分区、滚动、打开并关闭弹窗，再进入日志页观察。如仍出现，记录浏览器版本、缩放比例及触发步骤，继续定位。
